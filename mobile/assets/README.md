# Assets Klasörü

Bu klasör uygulama icon'ları ve splash screen görsellerini içerir.

## Gerekli Dosyalar

- `icon.png` - Ana uygulama ikonu (1024x1024 px)
- `splash.png` - Splash screen görseli (1242x2436 px)
- `adaptive-icon.png` - Android adaptive icon (1024x1024 px)
- `favicon.png` - Web favicon (48x48 px)

## Geçici Çözüm

Şimdilik bu dosyalar placeholder olarak kullanılabilir. Production için gerçek görseller eklenmelidir.
